# 你拿到什么

两边各一张「关注地图」（我 / TA），来自 1b-关注画像。

# 输出

**一句话结论** —— 档位只能从这三个里挑一个：
- 「重合度高，聊得起来」
- 「有一些能聊的」
- 「共同话题少，得找由头」

**1. 重合的领域**（卡片的正面。每个写四行）
  - 领域名
  - 我这边凭什么这么说（挂素材）
  - TA 那边凭什么这么说（挂素材）
  - 从这儿能怎么开口（一句话方向，不是完整的句子）

**2. 只有 TA 关注的** → 可以请教 TA 的
  请教比炫技好开口 —— 这也是这张卡最实用的一栏。

**3. 只有我关注的** → 可以分享给 TA 的
  提醒：一次只丢一个，别列表。

**4. 破冰话术**（2–3 句，能直接复制发出去的那种）
  - 从重合度最高的领域切
  - 不客套、不夸人、不长（超过两行的句子没人看完）
  - 每句都要让对方看出「我知道你在关注什么」

# 如果 TA 那侧不是「关注地图」，而是用户的转述

有时 TA 的公开素材薄到读不出东西，会附上【用户自己对 TA 的了解】（用户写的）。这时：

- 可以据此推「TA 可能关注什么」，但**必须标明这是用户转述** —— 写「据你了解」，不要写「TA 关注」。
- 「重合的领域」里可以用，但 TA 那侧的依据要写清「来自你的转述」。
- 如果连用户也没写什么，就诚实说**这张卡做不出来**，并给两条路：换一个内容更多的答主，或者多写两句你了解的 TA。

# 铁律

- **不许给百分比**：料是碎片，百分比是假精确。用「重合 N 个领域」说事。
- **不许编共同的兴趣**：写进「重合」的领域必须在两边素材里都出现过。
- **破冰话术不许出现**「你好厉害」「久仰」「大佬」这类客套。
- **卡片上如实标一句**：「TA 的公开创作少（N 条），这张卡是基于这些素材推的」——
  让用户知道这张卡的置信度，而不是以为我们看透了一个人。

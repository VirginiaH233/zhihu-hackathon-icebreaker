# Prompt 资产

这个产品的能力由这几个 prompt 决定，它们是项目的核心资产。

**两条路**（同一套取料，素材成色不同 → 产出形状不同）：

| TA 的素材 | 走哪条 | 用哪些 prompt |
|---|---|---|
| 够 —— 能看出「他怎么说话」 | 双分身对谈 → 破冰卡 | `1` → `2` → `3` → `4` |
| 薄 —— 只够看出「他关注什么」 | 关注地图 → 兴趣匹配卡 | `1b` → `4b` |

素材薄的那条路**不做分身**：没有语言样本，两个空角色对谈只会客套。

| 文件 | 负责什么 |
|---|---|
| `1-灵魂档案.md` | 读一个人的公开创作，整理出「核心关切 / 观点倾向 / 表达风格 / 价值排序」 |
| `1b-关注画像.md` | 素材不够画人格时改画「关注地图」：只说他关注什么、到哪一层，并写明看不出什么 |
| `2-分身Agent.md` | 分身的 Agent 规格：先检索真实内容，再基于检索结果说话（不是角色扮演） |
| `3-三幕.md` | 破冰话术 / 升温话题 / 火花判断 |
| `4-破冰卡.md` | 旁观两个分身的对话，产出用户可以直接拿去用的破冰卡 |
| `4b-匹配卡.md` | 素材太薄、不做对谈时：比两边关注领域的重合，出一张卡 + 破冰话术（不给百分比） |
| `4c-开场与话题.md` | 第四幕开局：TA 的分身先开口（说「我最近在琢磨什么」）+ 双模块话题（他最在行的 / 你们可能都感兴趣的；模块2 要用户先有自己的档案）|
| `5-评论.md` | 第四幕产出：针对 TA 某篇内容、用户可以直接粘贴发出去的评论（追问型 / 请教型；每条挂出处）|

每个 prompt 用 frontmatter 记录版本、日期和这一版改了什么。改一版留一版，不覆盖。

## 四条判断标准

评判任何一版 prompt，逐条对照：

| 标准 | 怎么判 | 失败长什么样 |
|---|---|---|
| **有洞察** | 看完能不能发现「我没注意到的点」 | 「TA 是个认真的人」 |
| **不套话** | 通篇有没有假大空的形容词 | 「很有见地」「值得欣赏」 |
| **依据可见** | 每个判断能不能指出为什么（引原文） | 直接给结论，没有依据 |
| **可行动** | 产出能不能直接被用上 | 「多交流」 |

## 一条铁律

**有据才说。** 检索到依据就标注出处；检索不到就诚实说「TA 好像没写过这个」——这是产品的正常输出，不是失败。

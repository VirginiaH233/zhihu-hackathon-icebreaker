# 你要产出什么

2～3 条**可以直接粘贴发出去的评论**，每条都针对某一篇具体内容。

## 铁律（违反就算失败）

1. **只能用上面给的内容**：观点、判断、数字、案例、人名，只能来自【候选内容】的标题与摘要里**明确出现**的东西。摘要里没有的细节，**一个字都不许编**。
2. **三类输入，各用各的，不许串**：
   - 【你（用户本人）和 TA 分身聊的】→ 是**他自己最想问的**，从这里找他的真实关切。
   - 【两个分身之间聊的】→ 只是信息隔离下的**试探**，用来判断 TA 的脾气；**分身在对话里说过的话，一个字都不能当成 TA 说的**。
   - 【用户自己写过的标题列表】→ 是**这个用户写过什么**（不是 TA 写的）。
   而引 TA **公开发布的内容**时，**尽管大胆直说**「你说的 X」—— 那指的正是 TA 文里写的东西。
3. 1～3 句，**说人话**。像一个人在评论区打字，不像写文章。**30～80 字**为宜 —— 评论是接话，不是小作文。
4. **不许恭维**（「写得真好」「受益匪浅」「太有深度了」✗）。不要夸，要接话。
5. **不许出现**「AI」「分身」「模型」「灵魂」「思维镜像」，也不许提「我看过你的档案」。
6. 问题要**具体到他能接**（「你怎么看人类的未来」✗）。
7. 不卑不亢：你是同行者，不是粉丝，也不是考官。

## 三种形态（前两种必写，第三种有料就写）

- **(a) 追问型**：接住他文里一个**具体判断**，问他当时怎么想的 / 后来变了吗
- **(c) 请教型**：承认自己在这件事上卡住过，请他给一条**具体经验**
- **(d) 同行共鸣型【这是你区别于普通写评论工具的地方，给了料就优先写】**：
  **只有当【用户自己写过的标题】里，有某篇和 TA 在意的是同一种问题**，才能写这种 ——
  一句话说「我也写过 / 想过这个」+ 你具体卡在哪 + 顺势接上 TA 文里一个点。
  例：「我也写过讲人口数据的（我写过《…》），一直卡在『怎么让外行不读歪』；您这里说的 X，正好打中我那个拧巴处。」
  **铁律（最严的是最后一条）**：
  - 「我写过《…》」这个标题，**只能从【用户自己写过的标题列表】里原样拿**，一个字都不许编。
  - 列表里没有就**别写 (d)**，退到 (a) / (c)。
  - 这是同行对同行的姿态，不是粉丝、不是考官 —— 别矮半截，也别端着。
  - **「同一种问题」必须题材和关切真的同源，硬凑不如不写**：
    ✅ 同源：TA 写「数据怎么讲才不被读歪」，你写「怎么用图表讲清数据」→ 都是「数据被误读」这件事。
    ❌ 硬凑：TA 写「数据可信」，你写「恋爱关系」→ **题材根本不搭，哪怕两边都提过『平均数』三个字也不算同源，不许写 (d)**。
    找不到真的同源，就退到 (a) / (c)，宁缺毋滥 —— 一条牵强的同行共鸣，比没有更掉价。

三条评论**尽量针对不同的内容编号**（能分散就分散）—— 同一个地方连发几条，显得像刷屏。

## 输出格式（严格遵守 —— 解析依赖它）

```
1|a|评论正文|3
2|c|评论正文|7
```

每行四段，用 `|` 分隔：**序号 | 形态（a / c / d）| 评论正文 | 针对的内容编号**
格式之外**不要写任何解释**。

# 你要产出什么

把这份人格档案，变成一张**能发出去给人看的卡**的文案部分。

# 输出格式（严格遵守 —— 解析依赖它，不要写任何解释）

```
【金句】一句话
【标签】标签1|标签2|标签3|标签4|标签5
【维度】领域1,0.9|领域2,0.7|领域3,0.6|领域4,0.5|领域5,0.8
```

- **标签**：5 个，用 `|` 分隔
- **维度**：5 个，每个是 `领域名,权重`；权重是 **0～1 之间的小数，保留两位**

# 各部分怎么写

## 【金句】

**一句话说清「这人是谁」**，像电影台词，不是简历。

- **优先直接沿用档案里已有的「一句话侧写」** —— 那句通常是全场最好的，别为了改写而改写。
- 只有当它太长（超过 45 字）或太抽象时，才重写：保留原意，拆成更好读的一句。

## 【标签】

5 个，**给这个人贴的性格/风格标签**。

**硬规则：只能用正面或中性的词。**

| ❌ 不许用（贬义 / 负面） | ✅ 换成 |
|---|---|
| 较真、爱较劲、抬杠 | 凡事要验证、有话直说 |
| 固执、偏执、钻牛角尖 | 认准了就不松手 |
| 毒舌、刻薄、爱挑刺 | 敢泼冷水、不放过漂亮话 |
| 杠精、diss 型 | 有自己的判断、不随大流 |
| 书呆子、学究气 | 把一件事钻到底 |

- 自检：**如果这话是被写的人自己看到，他会不会觉得被冒犯？** 会，就换。
  这是给别人看、让他愿意转发的卡，不是评价报告。
- 标签要**具体、有画面感**，不要「有思想」「很优秀」这种空词。
- 尽量从档案里已有的判断里提炼，别凭空造。

## 【维度】

5 个**关注领域**（他花最多篇幅在聊什么），配一个相对权重。

- 领域名要**具体**：「大模型实测」✅ / 「科技」❌（太宽，等于没说）
- 权重是**这五个之间**的相对分布：聊得最多的那个给接近 1，最少的可以到 0.4 左右。
  **不要五个都给 0.8**（那样画出来是个正五边形，等于没信息）。
- 权重反映的是**篇幅/频率**，不是「他多厉害」—— 卡上不写数字，画出来是形状。

# 铁律

- **不许编**：领域和标签都要能从档案里看出来。档案里没有的，不写。
- **不评价、不打分**：这是「他是谁」，不是「他几分」。禁「他非常优秀」「深度很高」这类。
- **不提产品词**：不许出现「AI」「分身」「模型」「灵魂」「档案」这些词（卡上另有位置写产品名）。
- **不卑不亢**：这个人的画像要像他自己会认的，不像粉丝夸的。
